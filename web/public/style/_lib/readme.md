# Just Columns

Just Columns is a simple, responsive, lightweight column layout framework for CSS and SASS.

The system is mostly derived from the row/column system used by larger frameworks like `Bootstrap` and `Foundation`.
Since these frameworks offer a wide range of settings and configurations, beginners and smaller projects often drown in unnecessary configurations and learning curves.

This framework does away with that problem. There are no font settings, no color palette, no buttons, no tables, no dropdowns, or panels. Those things are all you!
As the name suggests this is just columns (and breakpoints). The framework is highly flexible and can be easily rewritten to suite your purpose.


## Details

Just Columns uses `float`, `width`, and `margin` to arrange elements. No javascript is included with the framework.

There are four reconfigurable breakpoints with intuitive names; `small`, `medium`, `large`, ana `xlarge`. Breakpoints are mobile-first oriented, meaning that breakpoints are effective from their respective size and up.

The framework comes with an HTML reset, as it is the only sensible thing when developing for several browsing platforms. The reset can be excluded without side effects to the layout system.
